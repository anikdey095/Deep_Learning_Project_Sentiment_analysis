# Deep_Learning_Project_Sentiment_analysis
An end-to-end Deep Learning &amp; NLP application for multi-class emotion classification (Joy, Sadness, Fear, Anger, Love, Surprise). Implemented RNN, LSTM, GRU, and Bidirectional GRU architectures, integrated Hugging Face Datasets, and served predictions via an async FastAPI backend with an interactive web UI. Fully deployed on Render.
